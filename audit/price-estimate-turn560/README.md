# 显式币种与Token费用估算

## 本批范围
模型增加priceCurrency（USD、CNY或null）及priceCachedInPerM（每百万缓存输入Token单价）。现有输入/输出价格语义和priceVersion=1保持不变，未知币种不推断成人民币或美元。MCP更新模型、配置校验、Schema和Android编辑器共用这些字段。
按当次请求捕获的模型快照估算，不套用当前价格重算历史；旧账本无tokenCostEstimate则保持未估算。估算使用BigDecimal，金额写成十进制字符串。每种币种单独汇总，不自动换汇，不提供跨币种总额。

## 公式与未知语义
费用估算=((prompt_tokens-cached_tokens)*普通输入单价+cached_tokens*缓存输入单价+completion_tokens*输出单价)/1000000。
reasoning_tokens属于completion_tokens子集，不重复计入；cached_tokens属于prompt_tokens子集，不重复计入。
仅对已发送、完整HTTP2xx、报告有效usage的尝试估算。缺币种、缺输入/输出价、非零缓存但缺缓存价、未知缓存分割且价格不等时，金额为null，不当零。若缓存价与普通输入价完全相等，缓存占比未知不影响金额；输入量为0无需缓存分割。已发送但失败/截断的尝试单列为未估算。
输入价0与未知null不同；旧版无priceVersion且0/0的配置依然未知。仅补币种不能使旧0/0意外变成免费。保持历史价格、拒绝负数/非数/超界数值，读到不匹配的保存估算时记录部分读取错误。

## 选路与兼容
cheapest_first仅在已知价格的候选采用同一明确币种时可比较；币种混合或部分缺失时保留原序并附currency_not_comparable。全为旧无币种价格时保留原有排序以兼容旧配置，同时附legacy_currency_unset；此排序结果不是实际金额。
MCP自定义命名46f13d25已获用户验收，本批不改它的7个发布文件。

## 用户界面
提供商模型基础页增加计价币种与缓存输入价，价格输入改纵向全宽避免窄屏横排。模型价格标签显示USD/CNY或币种未设，不再统一使用人民币符号。用量面板显示每币种的Token估算、已估算与未估算次数，并明确不是供应商账单。
本估算不涵盖工具费、税费、阶梯价、缓存创建费或供应商折扣；账本仅保留当前窗口，预算扣限仍禁用。不得把本批作为金融实账或硬消费上限。
